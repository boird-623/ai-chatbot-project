🤖 小唐 — AI 智能聊天机器人

基于 Deepseek + Gradio 构建的对话式 AI 助手，支持多轮对话与自定义人格设定。

✨ 功能特性
- 调用 Deepseek API 实现高质量自然语言对话
- 基于 Gradio 构建 Web 交互界面，无需前端开发经验
- 支持自定义 System Prompt，灵活设定 AI 角色
- 支持多轮对话上下文记忆

🛠 技术栈
| 组件 | 技术 |
|------|------|
| AI 模型 | Claude API (Anthropic) |
| Web 框架 | Gradio |
| 语言 | Python 3.x |
| 部署 | Hugging Face Spaces |

🚀 快速开始
pip install gradio anthropic
# 配置 .env 填入 API Key
python app.py
